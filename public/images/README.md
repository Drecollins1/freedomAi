# Real imagery

Files here are referenced from `src/lib/content.ts`.

| File | Used by |
| --- | --- |
| `testimonial-1…6.jpeg` | `testimonials.gallery` — the community slider |
| _(unset)_ `telegramScreenshot` | "How the AI reaches you on Telegram" — drawn mock until set |
| _(unset)_ `owner.photo` | The accountability section — monogram until set |

The originals were renamed from `WhatsApp Image ….jpeg` to `testimonial-N.jpeg`:
spaces and parentheses in filenames have to be URL-encoded and break on some
hosts.

Rules for anything added here:

- Real screenshots only. A mock presented as a genuine post or result is
  misleading, and in a trading context that is a regulatory problem, not just
  an honesty one.
- Blur or crop other members' names, handles and phone numbers before
  publishing a chat screenshot.
- Screenshots showing money results must keep the individual-results
  disclaimer next to them on the page (see `testimonials.resultsDisclaimer`).
